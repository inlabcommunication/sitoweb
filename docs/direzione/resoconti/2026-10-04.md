## Sito Inlab: valutazione copertine reel da Meta (ricevuto 04/10 ~03:06, nessuna implementazione)

1. **oEmbed non più utilizzabile:** dal 3/11/2025 Meta ha tolto `thumbnail_url` (e `author_name`) dalle risposte di `/instagram_oembed`, anche con token; suggerisce di leggere i metadati HTML della pagina (è scraping: escluso).
2. **Strada ufficiale fattibile:** Instagram Graph API "Business Discovery": con l'account Instagram professionale di InLab si leggono i media pubblici di altri account Business/Creator per username; per i reel è disponibile `thumbnail_url`. Il server cerca il reel giusto confrontando il codice nel link tra i media recenti del cliente (limite ~200 media).
**Limiti:** funziona solo se l'account del cliente è professionale (Business o Creator, quasi sempre per chi fa social con InLab); serve lo username del cliente (ricavato dal link o da un campo in dashboard); i reel molto vecchi richiedono di sfogliare più pagine.
3. **Cosa serve a Nicola (30–60 minuti, una volta):** account Instagram InLab professionale collegato a una Pagina Facebook; app su developers.facebook.com (tipo Business, prodotto "Instagram API con login di Facebook"); permessi `instagram_basic`, `pages_show_list`, `pages_read_engagement` (con il suo account che ha un ruolo nell'app bastano senza revisione Meta, salvo cambi di Meta); token di lunga durata (meglio "utente di sistema" in Business Manager, non scade; in alternativa token da 60 giorni da rinnovare); variabili `META_IG_TOKEN` e `META_IG_USER_ID` in Vercel (Impostazioni > Environment Variables), **mai nel repo né in chat**: le inserisce Nicola direttamente.
4. **Come:** pulsante "Importa copertina da Instagram" accanto al campo Copertina in dashboard → `/api/reel-cover` con autenticazione admin (stessa verifica Firebase di `/api/publish`) → il server valida il link (solo `instagram.com/reel|p/<codice>`), chiede a Meta il `thumbnail_url`, lo scarica e lo carica su Cloudinary (firma già presente) → URL nel campo Copertina; Nicola salva come sempre. Il visitatore vede solo un'immagine nostra, WebP/AVIF, pigra (PR #84). Variante "Importa copertine mancanti" per tutti i reel senza copertina.
5. **Sicurezza:** solo admin (token Firebase verificato più lista email), solo host `instagram.com` con regex sul codice, si scarica solo il `thumbnail_url` restituito da Meta (host CDN di Meta/Facebook), limite di richieste al minuto, token solo lato server, nessun dato personale salvato.
6. **Costi:** API Meta gratuite (~200 chiamate/ora); Cloudinary ~30 immagini piccole, trascurabile.
7. **Se Meta nega, il token scade o il cliente non è professionale:** messaggio chiaro in dashboard ("copertina non disponibile da Instagram: caricala a mano"), il campo resta com'è, nessun errore per il visitatore; con il token da 60 giorni, avviso in dashboard quando sta per scadere.
8. **Stima:** circa mezza giornata più l'analista prima del merge. **Non è fattibile senza token:** senza l'app Meta non esiste un modo ufficiale.
**Percorso minimo:** Nicola crea app e token, conferma i nomi delle variabili in Vercel; Sito Inlab implementa A più "tutti in un colpo" e prova con un suo reel. Fino ad allora la copertina manuale resta possibile. **In attesa dell'ok del Direttore e di Nicola.** PR #84 (copertine lazy) all'analista.
